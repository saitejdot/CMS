# UI_DESIGN.md

## 🚨 CRITICAL DIRECTIVE

**DO NOT CHANGE THE PUBLIC VISUAL DESIGN.**

The visual identity of this project is established and must be preserved during all architectural rewrites (Phases 1-3). 

Future AI agents must **NOT** redesign the website, change colors, alter animations, or modify the typography merely because they lack the original conversation context.

## Preserved Elements
- **Colors**: The specific Tailwind configuration (`tailwind.config.ts`), CSS variables (`globals.css`), and inline styles.
- **Typography**: Existing font families, weights, and sizes.
- **Layout & Spacing**: The existing `Navbar`, `Footer`, `StoryCarousel`, and page structures.
- **Interactions**: Button hover states, theme toggling, and animations.
- **Components**: The notebook design for story reading, profile banners, and cards.

## Admin UI
The Admin Dashboard (`/admin`) is functional and utilitarian. It does not need to perfectly match the public visual identity, but it should remain clean and usable.
